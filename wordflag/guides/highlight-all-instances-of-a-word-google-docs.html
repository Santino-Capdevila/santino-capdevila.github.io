How to highlight all instances of a word in Google Docs

Google Docs can find every instance of a word, but it has no button to highlight them all at once. Here are three ways that work today, from quickest to most powerful.

Typical reasons to do this: checking a draft against a client's list of banned words, making sure a brand name is always written the same way, or spotting a word you overuse ("very", "really", "just").

1. See every match for a moment: Find (Ctrl+F)

  1. Press Ctrl+F (Cmd+F on a Mac).
  2. Type the word. Docs marks every match in the document and shows a count such as "1 of 3". The search ignores capitalization, so "Very" and "very" both count.
  3. Use the up and down arrows next to the box to jump from one match to the next.

The limit: these marks disappear as soon as you close the Find box. They are not real highlights, and you can only search for one word at a time.

2. Highlight them yourself: multi-select, then one click

Since 2022 Google Docs lets you select several separate pieces of text at once and format them together.

  1. Use Find (method 1) to see where the word appears.
  2. Close the Find box and select the first match.
  3. Hold Ctrl (Cmd on a Mac) and select each other match.
  4. Click the Highlight color button (the marker icon in the toolbar) and pick a color. Every selected match is highlighted.

This works well for a handful of matches in a short document. With dozens of matches, or a list of 20 banned words, it gets slow and it is easy to miss one.

3. Highlight every match automatically: a free Apps Script

Google Docs has a built-in script editor, Apps Script. This short script highlights every match of every word in your list, as whole words and in any capitalization.

  1. In your document, open Extensions > Apps Script.
  2. Delete the sample code and paste the script below. Edit the WORDS list.
  3. Click Save, then Run. The first time, Google asks you to authorize your own script; because you wrote it and it is not published, Google shows an "unverified app" warning. Choose Advanced, then Go to your project, then Allow.
  4. Go back to the document: every match is highlighted.
// The words or phrases to highlight (letters, spaces, hyphens and apostrophes).
const WORDS = ['very', 'really', 'in order to'];
const COLOR = '#fff475'; // yellow

function highlightWords() {
  const body = DocumentApp.getActiveDocument().getBody();
  WORDS.forEach(function (word) {
    // Whole words, any capitalization: "very" becomes \b[Vv][Ee][Rr][Yy]\b
    const pattern = '\\b' + word.replace(/[a-z]/gi, function (c) {
      return '[' + c.toUpperCase() + c.toLowerCase() + ']';
    }) + '\\b';
    let match = body.findText(pattern);
    while (match) {
      match.getElement().asText()
        .setBackgroundColor(match.getStartOffset(), match.getEndOffsetInclusive(), COLOR);
      match = body.findText(pattern, match);
    }
  });
}

Notes:

  • To remove the highlights, select all (Ctrl+A), click Highlight color and choose None. This also removes any highlights you added by hand.
  • The script only checks the main body of the document, not headers, footers or footnotes.
  • "very" does not match "every", because the script looks for whole words.
